# แผงแจ้งเตือน JangDi

กดกระดิ่งข้างโปรไฟล์เพื่อดูรายการล่าสุด 5 รายการ โดยไม่เปลี่ยนหน้า เดสก์ท็อป/แท็บเล็ตใช้ popover ใต้กระดิ่ง และหน้าจอไม่เกิน 640px ใช้แผงด้านล่าง พร้อมปุ่มปิดและปุ่ม “ดูการแจ้งเตือนทั้งหมด”

- เปิดแผงเพื่อดูเฉย ๆ ไม่เปลี่ยนสถานะเป็นอ่านแล้ว
- กดรายการเพื่ออ่านและไปหน้างาน/คำขอ/ชำระเงินตามเส้นทางเดิม
- รองรับผลอนุมัติบริการและ Payment ID แบบเดิมด้วย งานใกล้ตัวเปิดรายละเอียดเพื่อสมัคร ส่วนงานที่ได้รับเลือกแล้วเปิดติดตามงาน
- หากรายการเป็นของอีกบทบาท จะแจ้งให้สลับผ่านเมนู โดยไม่พากลับหน้าแรกเงียบ ๆ และไม่เปลี่ยนเป็นอ่านแล้ว
- กด “อ่านทั้งหมด” เพื่อบันทึกสถานะผ่าน API เดิม หากล้มเหลวจะมีข้อความให้ลองอีกครั้งและคงสถานะเดิม
- รายการใหม่จาก socket เพิ่ม badge โดยไม่เปิด popup อัตโนมัติ และแสดงในแผงที่เปิดอยู่แล้ว
- Badge แสดงสูงสุด `99+` แต่ชื่อสำหรับ screen reader ระบุจำนวนจริง
- หน้า `/notifications` ยังคงอยู่ พร้อมตัวกรองทั้งหมด/ยังไม่อ่านและสถานะว่าง/โหลดผิดพลาด

ทั้งสองหน้าร่วมกันใช้ Pinia notifications store, NotificationList และ useNotificationActions เส้นทางของแต่ละรายการอยู่ใน `src/services/notificationNavigation.js` ไม่มี endpoint ใหม่

บนมือถือ แผงรองรับ Tab/Shift+Tab, Escape, คืน focus ไปกระดิ่ง และพักการเลื่อน/การโฟกัสเนื้อหาด้านหลัง เมื่อปิดหรือเปลี่ยนขนาดหน้าจอจะปลดสถานะเหล่านี้ เดสก์ท็อปปิดได้ด้วย Escape คลิกนอกแผง หรือย้าย focus ออกไปทำงานในหน้าเดิม
