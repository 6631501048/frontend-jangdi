## โครงสร้างโค้ด

- `src/styles/design-system.css`: tokens, ตัวอักษร, control, ปุ่ม, layout, focus, responsive และ reduced motion ร่วม
- `src/styles/marketplace.css`: CSS ของฟีดผู้ว่าจ้างและผู้รับจ้าง ใช้ผ่าน scoped style เพื่อไม่รบกวนหน้าอื่น
- `src/components/AuthShell.vue`: โครงเข้าสู่ระบบ กรอกโปรไฟล์ และยืนยันอีเมล
- `src/components/JangDiMark.vue`: สัญลักษณ์แบรนด์ร่วมใน header และเมนู
- `src/composables/useDialogFocus.js`: focus สำหรับเมนู navigation, กล่องเปลี่ยนรหัสผ่าน และรีวิว
- Scoped CSS เดิมของหน้าต่าง ๆ เปลี่ยนจากสีซ้ำและข้อความเล็กเป็น tokens และ rem พร้อมคง layout เฉพาะงาน

## สิ่งที่เปลี่ยนตามประเภทหน้า

- ฟีด: แยกค้นหา ประเภทประกาศ หมวดหมู่ และผลลัพธ์ การ์ดแยกเวลา พื้นที่ ราคา และการกดทำรายการ
- แบบฟอร์ม: ช่องกรอกอ่านง่ายและมี accessible name, ขั้นตอนเลือกหมวดหมู่/รายละเอียด/ตรวจทานคงเดิม, สถานะปุ่มเลือกและ disabled ชัดเจน
- รายละเอียดงาน/บริการ: ขยายความกว้างเนื้อหาอย่างเหมาะสม แยกปุ่มหลัก/รองกับปุ่มฉุกเฉิน และเพิ่มความชัดเจนของข้อความติดต่อ
- งานของฉัน: สีสถานะอ่านง่าย แยกประเภทงานกับคำขอบริการ และเปิดการ์ดงานผู้ว่าจ้างด้วย Enter ได้
- โปรไฟล์: เปลี่ยนข้อความหลักเป็นไทย จัดข้อมูลเป็นหนึ่งคอลัมน์บนมือถือ แก้ฟิลด์เบอร์โทรที่แสดงซ้ำ และทำกล่องรหัสผ่านให้ใช้งานคีย์บอร์ดได้
- แอดมิน: ขยายเนื้อหาจากกรอบมือถือ 480px เป็นพื้นที่เดสก์ท็อปสูงสุด 1120px, ใช้ header/เมนูร่วมกัน, ตั้ง heading หน้าให้ถูกลำดับ, แก้ลิงก์โปรไฟล์ให้ชี้ `/profile` ที่มีอยู่จริง
- การเงิน: คงการคำนวณ ยอดเงิน ข้อความโหมดทดสอบ และสถานะการรับ/พัก/จ่าย/คืนเงินเดิม ปรับ presentation ให้สม่ำเสมอ

ไม่มีการเปลี่ยน service API, store, router guard, การคำนวณเงิน หรือ dependency ของโปรเจกต์ ชุดทดสอบสองไฟล์เปลี่ยนเฉพาะข้อความปุ่มที่ใช้ค้นหา ให้ตรงกับปุ่มภาษาไทย

## การตรวจ

- `npm test`: 74 รายการผ่าน ครอบคลุมงาน คำขอบริการ capacity การชำระเงิน การตัดสินใจแอดมิน เจ้าของประกาศ และการแจ้งเตือน
- `npm run build`: ผ่าน
- `node scripts/check-hirer-ui.cjs`: ตรวจฟีดผู้ว่าจ้างที่ความกว้าง 320–1440px, filters/search/pagination, เงื่อนไขซ่อนรายการ, keyboard และ contrast
- `node scripts/check-all-pages-ui.cjs`: 43 กรณีเส้นทาง รวม 172 การจัดวางที่ 320/390/768/1440px, ไม่มีแนวนอนล้น, ไม่มี runtime exception, ตรวจชื่อ control ขนาดปุ่มและคู่สีข้อความที่แสดงในข้อมูลจำลอง
- `node scripts/check-ui-interactions.cjs`: 13 กรณีเพิ่มเติม รวม focus/Tab/Escape/return focus ของเมนู, เปลี่ยนรหัสผ่าน, แก้ไขโปรไฟล์, ฟอร์มหลายขั้นตอนและย้อนกลับ, สถานะสมัครงาน, error/retry และข้อความ 200%
- `node scripts/check-feed-ownership.cjs`: ตรวจฟีดทั้งสองบทบาทกับเจ้าของประกาศรูปแบบ ID, `_id`, `id`, การค้นหา และการคงประกาศไว้ในหน้าจัดการ
- [แผงแจ้งเตือนและการตรวจ](notifications-ui.md): popover เดสก์ท็อป แผงมือถือ และหน้าประวัติพร้อมตัวกรอง

## ขอบเขตการยืนยันผล

Chrome ใช้ profile แยกและ API fixture ในสคริปต์ตรวจเท่านั้น ปุ่มสมัครงานส่งไป fixture และฟอร์มประกาศงาน/บริการหยุดที่ขั้นตรวจทาน ไม่มีการสร้างงาน ขอจ้าง ชำระเงิน หรือทำรายการแอดมินกับ backend จริง

การตรวจ contrast เป็นการตรวจข้อความที่ render ในสถานการณ์จำลอง ไม่ใช่ accessibility certification ครบทุกข้อมูลและทุกสถานะ Google Sign-In และแผนที่ภายนอกถูกปิดระหว่าง browser checks จึงอาจเห็นข้อความว่า Google ยังใช้งานไม่ได้ในภาพหน้า login; การทำงาน OAuth จริงไม่ได้เปลี่ยนและยังไม่ได้ตรวจในรอบนี้
